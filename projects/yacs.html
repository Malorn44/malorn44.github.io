Yet Another Course Scheduler (YACS)

PythonDjangoHTMLCSSJavascriptSQLite

YACS (Yet Another Course Scheduler) is a web application I developed to help students plan and visualize their academic schedules. The app allows users to input courses, view conflicts, and explore possible scheduling options through an interactive interface. The project was implemented using Django for the backend, with HTML, CSS, and Javascript for the frontend. SQLite was used as the database to store course information and user schedules. The app emphasizes usability and clarity, providing visual feedback on schedule conflicts and course selection.
